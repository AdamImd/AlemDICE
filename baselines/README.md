# Language-agent baseline

The AAAI artifact retains only the Alem language-agent evaluator and the
team-formation methods used by the submission. See
[`llm/README.md`](llm/README.md) for its components and
[`../EVALUATION.md`](../EVALUATION.md) for the comparison contract.

Install with:

```bash
uv sync --frozen --extra baselines-llm
```
